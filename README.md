### 💡 O que faz?

Transforma seu extrato CSV em um chatbot que entende perguntas como gente:

- "quanto gastei em alimentação?"
- "qual foi meu maior gasto?"
- "quanto foi o total?"

Sem API, sem internet. Lógica pura em Python.

### 🛠️ Techs usadas
- **Python 3**
- **Pandas** - leitura e filtro de dados
- **Lógica de NLP simples** - `if in` pra entender intenção
